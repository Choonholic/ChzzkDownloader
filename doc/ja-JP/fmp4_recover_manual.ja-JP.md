fMP4 Recoverは、ダウンロードしたFragmented MP4（fMP4）ファイルの一部のセグメントが破損している場合に、可能な範囲で映像データを復旧するための実験的な復旧ツールです。

ファイル内のセグメントを解析し、正常なメディアデータを可能な限り復旧した後、新しいMP4ファイルを作成します。

## 前提条件

fMP4 Recoverを使用するには、FFmpegとFFprobeがインストールされている必要があります。

インストール方法については、`how_to_install_ffmpeg.ja-JP.pdf`を参照してください。

## 使用方法

復旧するファイルを指定して`fMP4Recover.exe`を実行します。

```
.\fMP4Recover.exe "video.ts"
```

復旧するファイルを`fMP4Recover.exe`にドラッグ＆ドロップして実行することもできます。

復旧が完了すると、次のように元のファイル名に`_fixed`を追加した新しいファイルが同じディレクトリに作成されます。このとき、元のファイルは変更されません。復旧が正常に行われたことを確認した後は、元のファイルを削除しても問題ありません。

```
video.ts
video_fixed.mp4
```

## 制限事項

fMP4 Recoverは、現在確認されている特定の形式のFragmented MP4ファイルの破損を復旧するためのツールです。解析済みの形式とは異なる原因で破損している場合や、ファイル構造または破損の形式が異なる場合は復旧できません。

また、復旧できないセグメントは出力ファイルから除外されるため、該当する区間の映像または音声の一部が欠落する場合があります。

元のファイルに十分な正常なメディアデータが残っている場合にのみ復旧できます。復旧したMP4ファイルが正常であることを確認するまでは、元のファイルを保管してください。
